# Target SDK 36 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Target Android 16 with a supported Android build toolchain and publish the verified upgrade.

**Architecture:** Update the existing single-module Gradle build and regenerate the wrapper. Verify the packaged configuration for both variants without changing app sources.

**Tech Stack:** Android API 36, AGP 8.10.1, Gradle 8.11.1, Kotlin Gradle Plugin 2.2.21.

**Spec:** `docs/superpowers/specs/2026-10-27-target-sdk-36-design.md`

## Global Constraints

- Keep `compileSdk 36`, `minSdk 25`, existing app IDs, version, signing and dependency declarations.
- Leave app source code and source manifest unchanged; don't stage pre-existing untracked files.

## Review Focus

- Incomplete wrapper upgrade: verify the wrapper version and regenerate its JAR and scripts.
- Incorrect SDK metadata in one build variant: inspect both APK manifests.
- Kotlin plugin mismatch or release-only packaging failure: compile both variants and run unit tests.
- Platform behavior changes: run navigation and edge-to-edge smoke checks on API 36 if an emulator is available; report what was not checked.

### Task 1: SDK and toolchain upgrade

**Files:**
- Modify: `app/build.gradle`, `build.gradle`, `gradle/wrapper/gradle-wrapper.properties`, `.gitignore`.
- Regenerate as needed: `gradle/wrapper/gradle-wrapper.jar`, `gradlew`, `gradlew.bat`.

**Interfaces:** Consumes the existing Android SDK installation (`platforms/android-36`); produces debug and release APKs targeting API 36.

- [ ] Build the current debug APK with `./gradlew :app:assembleDebug`; inspect it with `aapt dump badging app/build/outputs/apk/debug/app-debug.apk` and verify that the API 36 assertion fails (target is 35).
- [ ] Update Wrapper from Gradle 8.9 with `./gradlew wrapper --gradle-version 8.11.1 --distribution-type bin`.
- [ ] In `build.gradle`, set `com.android.application` to `8.10.1` and all three Kotlin plugins to `2.2.21`; in `app/build.gradle`, set `targetSdk 36`.
- [ ] Ignore the local `.kotlin/` plugin state directory; verify with `git check-ignore .kotlin/`.
- [ ] Rerun `./gradlew wrapper --gradle-version 8.11.1 --distribution-type bin` to regenerate all wrapper files with 8.11.1; confirm `./gradlew --version` reports 8.11.1.
- [ ] Run `./gradlew :app:assembleDebug :app:assembleRelease :app:testDebugUnitTest`; require `BUILD SUCCESSFUL`.
- [ ] Run `aapt dump badging` on `app-debug.apk` and `app-release.apk`, asserting `targetSdkVersion:'36'` and `sdkVersion:'25'` in both.
- [ ] If an Android 16 emulator is available, run existing navigation instrumentation tests and inspect the main screen for overlaps with system bars. Record any skipped runtime checks.
- [ ] Run `git diff --check`, verify GitNexus change scope, stage only the planned files and commit `build: target Android SDK 36`.
- [ ] Push without force to `origin/main` and verify that the remote ref equals the commit.
