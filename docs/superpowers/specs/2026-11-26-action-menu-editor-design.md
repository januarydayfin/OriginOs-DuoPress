# Редактор «Меню действий»

**Сценарий:** пользователь открывает вложенный редактор, чтобы добавить один пункт, изменить порядок или посмотреть настоящее меню. Список остаётся главным содержимым экрана; для добавления и предпросмотра не нужно прокручивать его до конца.

## Редактор

- В тулбаре: «Назад», заголовок «Меню действий», справа — глаз с описанием «Показать меню». Он открывает ту же панель, что и прежняя кнопка.
- Над списком — «Порядок в меню» и счётчик позиций из 16. В строке слева направо: значок, название, корзина, ручка перетаскивания. Внизу справа — закреплённый FAB «+». Последнюю строку можно прокрутить выше него.
- Как в Bargen, перетаскивание начинается за ручку; жест по остальной строке прокручивает список. Соседние строки уступают место во время жеста. При отпускании сохраняется итоговый порядок; при отмене остаётся исходный. Для TalkBack у строки есть действия «Выше» и «Ниже».

## Добавление одного пункта

«+» открывает диалог «Добавить в меню». У каждой плитки есть иконка и подпись. Порядок в сетке:

| Левая колонка | Правая колонка |
| --- | --- |
| Приложения › | Ярлыки › |
| Фонарик | Камера |
| Переключить VPN | Circle to Search |

- **Приложения:** сетку сменяет диалог с поиском по установленным приложениям.
- **Ярлыки:** открывается отдельный экран существующего подбора с поиском, раскрывающимися приложениями и обработкой доступа через Shizuku. Вход из редактора означает «добавить в меню»: выбор ярлыка не меняет основное действие кнопки телефона. В редакторе и в рабочей панели видна подпись ярлыка, а нажатие в панели запускает сам ярлык.
- **Четыре встроенных действия:** нажатие сразу добавляет пункт. Уже добавленная плитка остаётся на своём месте, недоступна и подписана «Уже в меню». Удаление пункта снова делает плитку доступной.
- Успешный выбор в любой ветке закрывает добавление и возвращает в редактор с новым пунктом в конце. Следующее добавление — через «+». «Назад» из выбора приложения или ярлыка возвращает к сетке без записи; из сетки — в редактор.

## Подходы к выбору ярлыка

Рассмотрены диалог по аналогии с приложениями и отдельный экран. Диалог делает переходы одинаковыми, но клавиатура и раскрытые группы приложений конкурируют за высоту окна. **Выбран отдельный экран:** он оставляет больше места результатам и позволяет использовать знакомый подборщик. Для плоского списка приложений достаточно диалога.

## Детали для реализации

- Сохранить существующие настройки и лимит 16 позиций. Предлагаемое поведение на границах: при пустом списке подсказать «Нажмите +, чтобы добавить действие»; при заполненном — рядом со счётчиком объяснить лимит и сделать добавление недоступным. Удаление снова освобождает место.
- Не добавлять приложение повторно; для ярлыка проверять пару «пакет + ID», поскольку подпись может измениться. В списках выбора помечать уже добавленные элементы. Использовать существующий формат `ShortcutAction`; если подпись пустая, показывать название приложения или ID ярлыка вместо сериализованной строки.
- Сохранённые ранее нестандартные и повторяющиеся строки остаются доступны для перестановки и удаления по позиции. Ошибка записи не закрывает подборщик и не выдаёт несохранённое изменение за успешное.
- Критерий проверки: добавить ярлык, переместить его за ручку, открыть панель глазом и запустить этот ярлык. После повторного входа в редактор порядок сохранён, а основное назначение кнопки телефона прежнее.
