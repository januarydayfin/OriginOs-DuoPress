# Выбор приложения и тактильный отклик в редакторе меню

Поправка к [дизайну редактора](2026-11-26-action-menu-editor-design.md) после проверки на телефоне.

**Выбор приложения.** Плитка «Приложения» открывает отдельный экран с заголовком, поиском и списком установленных приложений. «Назад» без выбора возвращает к сетке. Успешный выбор добавляет один пункт в конец меню и возвращает в редактор с закрытой сеткой. Уже добавленное приложение видно, но недоступно для повторного выбора.

**Перетаскивание.** При захвате ручки — один короткий тактильный сигнал; при фактической смене позиции — более лёгкий щелчок. Простое касание, прокрутка, отпускание и отмена не дают дополнительного отклика. Используется системная тактильная обратная связь с учётом настройки вибрации касаний.

**Рассмотренные варианты.** Вместо прежнего диалога для приложений выбран экран по образцу ярлыков: с клавиатурой остаётся больше места для результатов. Один сигнал только при захвате не даёт почувствовать смену позиции; выбран отклик на оба события.
