# DuoPress без HiddenApiBypass

## Цель

Удалить `org.lsposed.hiddenapibypass:hiddenapibypass` и обращения DuoPress к скрытым Android API, не теряя ярлыки приложений. Эксперимент в ветке `experiment/no-hidden-api-bypass` подтвердил запуск ярлыка T‑Pay по физическому двойному нажатию на vivo V2515: новый путь использовал публичный `LauncherApps` внутри Shizuku UserService.

## Варианты

- **Shizuku UserService — выбран.** Сохраняет общий каталог ярлыков и формат сохранённых назначений. Требует Shizuku v13+ и ожидания подключения при первом обращении.
- **Диплинки без Shizuku — не выбраны.** Не перечисляют произвольные ярлыки и не восстанавливают их по сохранённому ID. Требовать смены системного лаунчера ради ярлыков тоже не нужно.
- **Оставить обход ради ярлыков — не выбрано.** Уменьшает объём изменений, но не достигает цели удаления зависимости.

## Поведение

- Для ярлыков: **Android 11+; Shizuku API 13+ от ADB shell; root и Sui не поддерживаются**. Для всех остальных действий эти требования не меняются. `minSdk 25`, `targetSdk 36`; без новых разрешений, ролей, зависимостей для обхода или изменений манифеста.
- Один UserService для списка, ленивой загрузки иконок и запуска из двойного нажатия, диагностики и меню. В UserService — только публичный `LauncherApps`, запросы от DuoPress и ограниченные по размеру иконки. Если иконка недоступна, используется значок приложения. Подключение не блокирует UI, имеет тайм-аут 5 секунд и восстанавливается после отключения Shizuku. Без постоянного демона.
- На Android 11 запуск через `LauncherApps.startShortcut`; на Android 12+ — через `PendingIntent` ярлыка, на Android 14+ с явным разрешением фонового запуска. `SwipeEntryActivity` и меню дожидаются завершения попытки запуска, не отправляя один выбор дважды. Обычные действия не ждут Shizuku.
- Формат `shortcut:<package>:<id>:<label>`, ключи и сохранённые назначения не меняются. Старый `special:circle_to_search` остаётся распознаваемым только для совместимости: на существующих назначениях показываем «Circle to Search — недоступно» и записываем это в диагностику при запуске. Не удаляем значение, не запускаем вместо него другое действие.
- Circle to Search исчезает из новых назначений и из штатного меню по умолчанию. Убираем код запуска, специальную задержку меню, экран настроек ассистента, который обслуживал эту функцию, и устаревшие описания на русском и английском. Исторические спецификации не обновляем.

## Проверка

Сборка debug и release, unit-тесты и инструментальные проверки; в `debugRuntimeClasspath` и `releaseRuntimeClasspath` нет HiddenApiBypass. На реальном vivo проверить список и иконки, старое назначение, холодный запуск ярлыка из жеста и из меню, сообщение при старом Circle to Search и работу фонарика/камеры без Shizuku. Эмулятор и ADB-интент не заменяют физический жест на vivo.
